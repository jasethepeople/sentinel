# Security policy

This repository is an offline, fixture-only prototype. Please report suspected security defects through GitHub's private vulnerability reporting for this repository, if available. Do not include credentials, private scope keys, or sensitive target data in public issues.

A report should include the affected version, a minimal reproduction, expected versus actual behavior, and whether any tool invocation reached beyond the built-in fixture map. Do not test third-party systems while investigating this project.

The maintainers make no guarantee of response time or production suitability. This project is not a substitute for a professional security assessment.
